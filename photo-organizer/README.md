# Photo Organizer

本地优先的照片整理、地图相册、旅行手帐和日程规划助手。

## 产品目标

扫描本地照片的 EXIF 元数据，按日期和地点整理照片；用户可以在地图上查看拍摄分布，进入地点查看缩略图，并根据地点变化生成旅行时间线和手帐。

## MVP

- 扫描本地照片并读取拍摄日期和 GPS
- 按日期、城市和地点聚合
- 在地图上显示照片数量
- 点击地点查看照片缩略图
- 生成按日期排列的照片时间线
- 不上传原图，支持删除本地索引

## 后续功能

- 旅行/工作类型标注
- 根据地点变化识别旅行片段
- 日历中的旅行手帐视图
- 未来行程和待办规划
- 重复照片和相似照片检测
- 地点隐私模糊化

## 技术方向

Python、Pillow/ExifTool、SQLite、FastAPI、React、MapLibre 或 Leaflet、FullCalendar。

## 隐私原则

照片、GPS 和日程默认只在本地处理；仓库不提交真实照片、真实坐标或个人日历数据。
