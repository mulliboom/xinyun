# Photo Organizer Agent Instructions

这是一个本地优先的照片整理和旅行手帐项目。

## Scope

只处理照片元数据索引、日期和地点整理、地图可视化、旅行手帐和日程规划功能。

## Rules

- 不读取或提交用户未明确选择的照片。
- 不提交真实照片、GPS、日历或其他个人数据。
- 原图默认保留在用户本地，不上传到第三方服务。
- 将照片索引和 UI 分离，核心逻辑放在 `src/`。
- 为 EXIF 解析、聚合和时间线生成添加测试。
- 处理缺失 EXIF、错误 GPS 和重复扫描。
- 用户可见功能变化要更新 README 和 TODO。

## Definition of done

实现功能、补充测试、运行测试，并在最终说明中列出修改文件和验证结果。
